# PORTEXA

Portexa is a logistics and shipment management platform built with Flask and SQLite.

## Features

- Shipment Management
- Customs Clearance Management
- Transportation Companies Management
- User Management
- Support Ticket System
- Advertisement System
- Reports & Analytics
- Notifications System
- Role-Based Access Control

## User Types

- System Administrator
- Trader
- Customs Broker
- Transportation Company
- Technical Support
- Advertiser

## Technologies

- Python
- Flask
- SQLite
- HTML5
- CSS3
- JavaScript
- Bootstrap

## Installation

```bash
git clone https://github.com/YOUR_USERNAME/Portexa.git
cd Portexa

pip install -r requirements.txt

python app.py
```
